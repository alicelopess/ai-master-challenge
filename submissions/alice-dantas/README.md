## Principais decisões estratégicas

### **DEC 001 - Commits do projeto**

**Problema:** O [CONTRIBUTING.md](../../CONTRIBUTING.md) apresenta a regra de que PRs contendo arquivos modificados fora de [submissions/](../../submissions/) serão rejeitados. Essa regra inclui o arquivo [.gitignore](../../.gitignore), que ignora a pasta submissions.

**Análise:** Se a pasta [submissions/](../../submissions/) for ignorada, meus commits não terão registros do meu trabalho.

**Decisão:** Usar o claude code para definir um fluxo de commit seguro, mantendo a rastreabilidade do código e a segurança contra diretórios e arquivos que não devem ser rastreados. [Avaliar Fluxo de Commit](./docs/commit-flow.md)

**Impacto:** Segurança contra diretórios e arquivos que não devem ser rastreados.
